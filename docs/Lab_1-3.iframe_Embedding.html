1 웹사이트 임베딩

대시보드의 컨텐츠를 직접 제작하는 방법도 있지만 이미 잘 만들어진 웹사이트를 대시보드에 불러오는 방법도 있다. 이것을 임베딩(embedding)이라고 하는데, HTML의 iframe 태그를 사용한다.

태그의 구조는 다음과 같다.

<iframe
  src= 웹사이트 링크 # iframe으로 불러올 웹페이지의 URL
  loading="lazy" # 화면에 보이기 전까지 iframe 콘텐츠 로딩을 지연(HTML5 표준)
  style="width: ; height: ; border: " # 가로, 세로, 테두리 설정
  allow="web-share; clipboard-write" # iframe 내에서 웹 공유 API 사용, 클립보드 복사 허용>
  
</iframe>

보통 여기에서 src 부분만 다르게 작성하고, width, height, border를 알맞게 설정해주면 된다. 다만 웹사이트 자체에서 iframe을 차단하고 있다면 그 웹사이트는 대시보드에 불러와서 사용할 수 없다.

유튜브는 영상 > 공유 > 퍼가기로 iframe 태그를 받을 수 있고, 직접 세부사항을 수정할 수 있다.

<iframe width="800" height="600" 
src="https://www.youtube.com/embed/rxOMhQwApMc?si=_K_qCxFqdn4qJTLH" 
title="YouTube video player" 
frameborder="0" 
allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share" 
referrerpolicy="strict-origin-when-cross-origin" 
allowfullscreen>

</iframe>

Our World in Data라는 웹사이트에서는 아름다운 인터랙티브 시각화 자료를 제공하는 것으로 유명하다. 여기에서 원하는 자료를 찾았다면 Share 버튼을 누르고 </> Embed라는 옵션을 누르면 iframe 태그가 나와 그것을 그대로 복사-붙여넣기 하면 된다.

<iframe
src="https://archive.ourworldindata.org/20250624-125417/grapher/annual-change-forest-area.html"
loading="lazy"
style="width: 100%; height: 600px; border: 0px none;"
allow="web-share; clipboard-write">
</iframe>

2 예시 대시보드 만들기

위의 사항을 바탕으로 예시 대시보드에 접속하여 구성을 살펴본다.

대시보드가 세 개의 페이지(Plot, Map, iframe)로 나뉘어져 있고, 각 페이지마다 행, 열, 탭셋과 같은 레이아웃 요소들이 배치되어 있다.

이 대시보드를 어떻게 제작할 수 있을지 생각해 본다. 대시보드 제작을 위한 Quarto 다큐먼트를 생성한다.

아래는 해당 대시보드를 만들기 위해 사용된 코드이다. 참고하여 자신만의 대시보드를 만들어 본다.

2.1 YAML 헤더

다양한 theme을 실험해본다. scrolling:을 true로 두면 대시보드가 상하 스크롤이 가능해져 콘텐츠를 많이 넣을 수 있다는 장점이 있지만, 앞서 레이아웃 설정에서 배운 {height=} 옵션 사용이 불가능해진다.

---
title: "dashboard"
format: 
  dashboard:
    scrolling: false
theme: flatly
editor: visual
editor_options: 
  chunk_output_type: console
---

2.2.2 두번째 행의 탭셋: Static Plot

행을 설정하고 행의 상대적인 높이(80%)를 지정한다. 탭셋을 생성하기 위해 {.tabset} 태그가 사용되어야 함에 주의한다.

## Row {.tabset height="80%"}

그래프 카드를 생성하기 위해 ggplot2 패키지를 활용한다. 그래프 카드의 제목을 지정하기 위해 title= 옵션이 사용되어야 함에 주의한다. 이때 산출될 플롯의 크기는 fig-width와 fig-height로 조정할 수 있다.

#| title: Static Plot
#| fig-width: 15
#| fig-height: 6

library(tidyverse)

ggplot(data = iris, aes(x = Petal.Length, y = Petal.Width, color = Species)) +
    geom_point() +
    labs(
        title = "Relationship Between Petal Length and Width", # 그래프 제목
        x = "Petal Length (cm)", # x축 제목
        y = "Petal Width (cm)", # y축 제목
        color = "Species", # 범례 제목
    ) +
    theme_minimal()

다음 탭셋에는 인터랙티브 플롯을 생성하기 위해 ggplotly() 함수를 활용한다.

#| title: Interactive Plot
#| fig-width: 15
#| fig-height: 6

library(plotly)

p <- ggplot(data = iris, aes(x = Petal.Length, y = Petal.Width, color = Species)) +
        geom_point() +
        labs(
            title = "Relationship Between Petal Length and Width", # 그래프 제목
            x = "Petal Length (cm)", # x축 제목
            y = "Petal Width (cm)", # y축 제목
            color = "Species", # 범례 제목
        )

ggplotly(p)

2.3 Map 페이지

# Map

2.3.1 첫번째 열의 그래프 카드: Interactive NDVI Map of Seoul

Map 페이지를 보면 행의 구분 없이 2개의 열로 분할되어 있다. YAML 헤더에서 orientation: columns 설정을 하지 않았기 때문에 Row 설정을 먼저한 뒤 바로 Column 설정을 한다.

## Row

### Column {width="50%"}

leaflet 패키지를 활용하여 그래프 카드를 생성한다.

#| title: "Interactive NDVI Map of Seoul(2025.04.26.)"

library(tidyverse)
library(terra)
library(tidyterra)
library(sf)
library(leaflet)

SIGUN <- st_read("landsat/SIGUN/SIGUN.shp",
                 options = "ENCODING=CP949",
                 quiet = TRUE)
seoul <- SIGUN |>  
    filter(
        SG1_NM == "서울특별시"
        )

landsat_seoul <- rast("landsat/landsat_seoul.tif")
landsat_seoul_mask <- landsat_seoul |> 
  mask(seoul)

numerator <- landsat_seoul_mask[["B5_NIR"]] - landsat_seoul_mask[["B4_Red"]]
denominator <- landsat_seoul_mask[["B5_NIR"]] + landsat_seoul_mask[["B4_Red"]]
NDVI_2025 <- numerator / denominator

pal_numeric <- colorNumeric(palette = "RdYlGn",
                            values(NDVI_2025),
                            na.color = "transparent"
                            )

leaflet() |> 
  addTiles() |> 
  addRasterImage(NDVI_2025, colors = pal_numeric, opacity = 0.8) |> 
  addLegend(pal = pal_numeric,
            values = values(NDVI_2025),
            title = "NDVI of Seoul"
            )

3 대시보드 웹 상에 출판하기

블로그와 마찬가지로 다음의 절차에 따라 완성된 대시보드를 웹 상에 출판한다. 여기서는 Posit에서 제공하는 무료 출판 사이트인 Quarto Pub을 활용한다.

  • Quarto Pub에 접속하여 계정을 만든다.

  • RStudio에서, 왼쪽 하단부의 Terminal 탭을 누른다.

  • 프롬프트에 다음과 같이 입력하고 실행한다

quarto publish quarto-pub (qmd 파일명).qmd
